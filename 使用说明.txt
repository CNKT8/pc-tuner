电脑性能优化助手 · v16.0  使用说明
================================================

【软件简介】
本软件为本地单机性能优化工具：不联网、不上传任何个人数据，
覆盖系统概览、实时监控、性能模式、进程管理、空间清理、硬件与风扇、
性能调度（CPU/GPU 频率与真超频）、安全扫描、录屏、网络加速
等 14 个功能页；v16.0 起账号 / 会员 / 排行榜已整体移除。
全品牌通用（Intel/AMD/NVIDIA 等），所有系统修改均可备份回滚。

【一、启动方式】
  · 双击「电脑性能优化助手.exe」（免安装、免 Python，绿色单文件）
  · 或双击「启动优化助手.bat」源码启动
  · v16.0 起没有登录框、不需要账号、不需要联网，双击直接进主界面
  · 每次启动仍显示 3.5 秒免责声明，随后进入主界面

【二、四种性能模式】（④ 性能模式页）
  ① 节能模式   节能电源计划，降低耗电/发热/风扇噪音
  ② 均衡模式   性能与耗电平衡，日常推荐
  ③ 高性能模式 高性能电源计划，响应更快
  ④ 野兽模式   卓越性能电源（强于高性能）+ CPU 全核拉满且禁止核心停放
               + 主动散热 + 睿频拉激进 + 关 PCIe/USB/硬盘节电
               + 游戏模式/网络调度优化 + 关游戏录制 + 开 HAGS + 关特效
               点击后【按 F5 确认激活】，所有项目可「全部恢复」
  · 所有修改前自动备份，可「全部恢复」

【三、十四个功能页】
  ① 系统概览   硬件信息主动检测（全品牌通用），一键导出系统报告
  ② 实时监控   CPU/内存/C盘/GPU 圆形仪表盘 + GPU/CPU 温度 + 磁盘/网络
  ③ 智能中心   v10 新增，见下方【智能中心五大工具】

  ⑤ 进程管理   内存占用排行，系统关键进程受保护（explorer 只重启不结束）
  ⑥ 空间清理   缓存白名单清理 + 大文件只读报告

  ⑨ 安全扫描   紧急病毒急救箱 + Defender 脱机指引 + 快速扫描/威胁历史

  ⑪ 捐款项目   支持开发者（微信收款码）

  ⑭ 网络加速   本机侧 TCP/DNS/MTU/QoS 优化，
               不做海外专线、不假装加速跨国延迟

【智能中心五大工具】（③ 智能中心页）
  ① 智能体检   一键只读检测 CPU/内存/C盘/温度/自启项，打分并推荐模式，
               确认后一键应用（高温→极速降温，紧张→均衡，高负载→高性能）
  ② 内存优化   实时内存占用；扫描并结束“你自己启动的”高内存程序
               （系统进程/explorer/杀毒自动排除）；可开 ≥88% 高内存预警。
               不做“内存整理/释放XGB”偏方，真正有效=关程序+减自启+加内存
  ③ AI帧生成   识别显卡真实支持的 DLSS4/DLSS3/DLSS2/FSR/AFMF/XeSS，
               一键打开显卡官方面板与系统图形设置、给游戏内开启指引。
               真帧生成由驱动与游戏完成，本软件不伪造帧数
  ④ 线路优化   五个公共 DNS 实测延迟（约15秒），标★最快，一键切换
               （自动备份可恢复）+ 刷新 DNS 缓存；网游加速请用商业加速器
  ⑤ 极速降温   显卡风扇 100% + CPU 限频 90% + 主动散热，高温应急，
               弹一次 UAC，「退出降温」一键恢复，关闭软件风扇也自动还原
  急救箱（⑨ 安全扫描页顶部）：自动检测本机 360 系统急救箱并启动，
               未装则跳 360 官方下载页；另提供 Defender 脱机扫描指引。
               第三方工具只检测/跳转，不捆绑、不代下载、不冒充杀毒。

【性能调度说明】（⑧ 性能调度页，v12 升级）
  ① CPU 频率上下限：最小/最大处理器状态（AC 交流 / DC 直流分别设置），
     滑条 1%~100% 按真实读回值显示（系统最小 1% 不再被强行抬成 5%），
     修改前自动备份、可一键恢复；
  ② 进程 CPU 亲和性：下拉选择进程（内存 Top16），可分配全部逻辑核/
     前一半核心/仅核心0/仅核心1，即时生效；系统关键进程受保护；
  ③ GPU 频率/显存频率锁频：软件自动检测驱动是否支持 nvidia-smi 锁频
     （NVIDIA）与 AMD 官方锁频接口，支持则真实写入上下限，不支持如实
     显示原因，绝不假装成功；
  ④ GPU 真超频（v12 核心升级）：软件直接调用 NVIDIA 驱动 NVAPI
     【SetPstates20】写入核心/显存频率偏移——与 MSI Afterburner 同款
     官方通道，是真实写入驱动，不是打开网页、不是模拟、不是假功能。
     滑条设置偏移 → F5 确认（超频须知 + 免责）→ UAC 授权后生效；
     「恢复默认」一键把偏移归零回出厂频率，可随时读回当前已应用偏移。
     推荐保守起步：GPU +100MHz / 显存 +200MHz，游戏或烤机验证稳定后
     再逐步增加；超频增加功耗发热，可能缩短硬件寿命，超频导致的
     显卡或 CPU 问题与软件无关；
  ⑤ CPU 超频：Windows 软件无法直接超 CPU 外频/倍频（受 BIOS/主板
     限制），本软件如实提示并引导官方工具（Intel XTU / AMD Ryzen
     Master 官方下载页），不代下载；
  ⑥ 不做假：驱动/硬件不支持的任何项目，一律如实显示原因 + 官方工具
     引导，不存在“点了没反应还显示成功”。

【兼容性说明（全品牌通用版）】
  · 电源/清理/进程/启动项/Defender/SMART/网络等功能基于 Windows 通用接口，
    Win10/Win11 各品牌电脑均可使用；
  · 风扇调速：NVIDIA 用 NVAPI、AMD 用 ADL 官方通道；Intel 核显与部分
    品牌机/笔记本/云显卡 VBIOS 锁定风扇策略，官方接口会明确返回不支持，
    软件绝不做假，此时请用显卡厂商官方工具；
  · CPU/主板温度与机箱风扇：系统未开放传感器时（服务器/虚拟机常见），
    在「⑦ 硬件与风扇」页一键接入免费开源的 LibreHardwareMonitor 即可，
    本软件不捆绑、不代下载，请从其 GitHub 官方发布页获取；
  · 真超频能力由驱动决定：NVAPI SetPstates20 接口大部分 NVIDIA 驱动
    开放（老驱动 461.09 在 GTX 1050 上已验证可用），接口未开放时
    软件如实显示并引导官方工具。

【六、常见问题】
  · F5 没反应？先点「野兽模式/超频」弹窗后再按 F5
  · 点按钮没反应？UAC 弹窗记得点「是」
  · 超频后没生效？超频需 UAC 管理员授权，弹窗时点「是」；
    完成后点「读取当前状态」即可看到已应用偏移
  · 风扇调不了？官方接口返回不支持即 VBIOS 锁定（品牌机/笔记本常见），
    软件会如实说明原因，可改用显卡厂商官方工具，不存在"调了没反应还显示成功"
  · 手动调速后软件崩溃？下次启动会自动恢复显卡自动调速（心跳保护）
  · CPU 温度显示 N/A？装 LibreHardwareMonitor 后在硬件页启动增强检测
  · 扫描提示 Defender 不可用？可能被第三方安全软件接管
  · 超频按钮不可用？当前驱动未开放 NVAPI 超频接口，属正常现象，
    按页面提示升级驱动或使用 MSI Afterburner 等官方工具

【七、⑫ 猫猫AI 页（v13 新增）】
  猫猫是住在软件里的本地 AI 小助手，离线运行、不联网、不收集数据。
  · 聊天：直接打字聊天，猫猫有自己的性格（自称"本喵"）
  · 调优：说人话就能让猫猫帮你调电脑，例如：
      "切到游戏模式" → 自动切野兽模式
      "切到省电模式" → 节能电源
      "我电脑太热了" → 开极速降温
      "帮我清理垃圾" → 扫缓存清理
      "内存占满了" → 扫高占用程序
      "优化一下网络" → 刷新 DNS
      "帮我体检" → 智能体检
      "杀一下毒" → Defender 快速扫描
      "全部恢复默认" → 一键回滚
  · 小游戏：
      "玩猜数字" —— 1-100 猜 7 次，猫猫会提示大了/小了
      "玩石头剪刀布" —— 直接出石头/剪刀/布
  · 顶部有 8 个快捷按钮，一键触发常用指令

【八、v16.0 移除的账号与会员功能】

  ● 为什么删
    会员/注册/登录/排行榜整套服务需要一台常开的服务器，实际发给朋友测试时
    对方电脑上没起服务、127.0.0.1 打不开，体验很差。按需求整体移除。

  ● 删掉的东西
    启动登录窗 / 游客入口 / 右上角账户区 / 账户面板（套餐 · CDK · 订单）/
    四处会员门禁（网络加速 · CPU 超频 · GPU 超频 · 风扇调速）/
    录屏的非会员 1080p·60fps 限制 / 会员黑金壁纸 / ⑮ 排行榜页 /
    本地账号 accounts.json 与 PBKDF2 校验 / cat_member.py 依赖

  ● 现在的状态
    所有功能对所有人无条件开放；软件回到纯本机工具，不联网、不要账号。
    %APPDATA%\PCPerformanceTuner 下遗留的 member.json、vip_bg.png 已不再读取，
    可以直接删掉。
